# Ministerio Público RN

Organización de desarrollo y gestión de proyectos tecnológicos.

## Proyectos

En este espacio se publican librerías, sistemas, herramientas y componentes desarrollados para nuestros proyectos.

## Desarrollo

Los proyectos publicados en esta organización buscan mantener:

- Código mantenible y escalable
- Componentes reutilizables
- Buenas prácticas de desarrollo
- Accesibilidad
- Consistencia visual
- Testing y validaciones automáticas
